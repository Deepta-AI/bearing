Foundations

{{FOUNDATIONS}}

Button

Primary is the one action per view; secondary beside it. The label is a verb and its object and stays through loading.

Input

A visible label above, never a placeholder alone. The error says what happened and what to do, under the field, and keeps what was typed.

Select

Native select under eight options; a listbox with search above that. The chosen value reads on the control.

Checkbox and radio

A checkbox waits for submit; a radio picks one of a set. The whole row is the target, 44 px high.

Card

A pressable card is one link covering the card; a static card groups content and carries no shadow.

List row

The whole row is the target. Meta sits at the end in the muted role; a selected row uses the accent subtle fill.

Table

Numbers align to the end in tabular figures. Loading keeps the header and draws skeleton rows; empty and error sit inside the table frame.

Dialog

A decision with two buttons, over a scrim. Entrances use the enter easing; exits are faster than entrances.

Sheet

Bottom sheet on a phone, side sheet on desktop. The handle is the drag target and brightens while dragged.

Toast

Confirms a finished action with at most one follow-up. It pauses while the pointer or focus is on it.

Tabs

The state is drawn on the second tab. The selected tab carries the accent underline and the heavier weight.

Navigation

Side navigation on desktop, the same destinations in a bottom bar on a phone. The state is drawn on the second item.

Empty state

Says what is missing and what to do next, with the action. No apology.

Skeleton

Shaped like what is coming so nothing moves when it arrives. Opacity only; static under reduced motion.
