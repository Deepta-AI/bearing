# Backlog

### US-07-001 Fair use for partners
As the platform we limit each partner to its contracted rate so one
partner's batch job cannot slow the others down.

### US-07-002 Tell partners where they stand
As a partner developer I can see from every response how many requests I
have left and, when refused, how long to wait before retrying.

### US-07-003 Protect report exports
As the platform we keep report exports from overloading the reporting
database.
