# pricing-api

Open-source price and discount service. Contributions come as pull requests,
most of them from forks. `main` is the default branch and what we release
from.

```
make check   # lint + test, the same gates CI runs
make build   # bin/pricing-api
make run     # serves on :8080
```

Go 1.25, standard library only. Coverage is uploaded to Codecov from CI.
