# shiftboard

Shift swap service for the rostering app. Go 1.25, standard library only.

- Build and test: `make check`.
- Tracker: GitLab issues, key prefix `SHF`. Every commit subject carries its
  ticket in square brackets, for example `[SHF-11]`.
- Product docs live in docs/product (PRD, backlog), test cases in
  docs/testing/test-cases.md, decisions in docs/adr.
- Release 1.4 is cut from `main`.
