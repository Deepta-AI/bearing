# ADR-0002: Responsive web only, no native apps in v1

Status: Accepted, 2026-07-10

## Context
Three developers, none with mobile experience. Tenants and vendors use
cheap Android phones and already reply to SMS.

## Decision
maintdesk v1 is one responsive web site plus SMS. No native iOS or Android
app and no push notifications in v1. Revisit after v1 is live.
