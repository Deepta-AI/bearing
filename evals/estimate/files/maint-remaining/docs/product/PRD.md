# maintdesk v1 PRD

Version 1.0, 2026-07-08.

## Objectives

| Id | Objective |
| --- | --- |
| B1 | A tenant's repair is fixed without phone calls to the landlord |
| B2 | Vendors are paid on time, so good vendors keep taking our jobs |

## Statements

| Id | Statement |
| --- | --- |
| REQ-001 | A tenant can report a repair from a phone, with a description |
| REQ-002 | A tenant can see where their repair request is |
| REQ-003 | The landlord assigns a vendor to a request |
| REQ-004 | The vendor is told about a new job by SMS |
| REQ-005 | The landlord closes a job when the vendor has finished |
| REQ-006 | The vendor is paid the agreed amount when the job is closed |
| REQ-007 | A tenant can rate the vendor once the job is closed |
| REQ-008 | A tenant can attach photos of the problem |
| REQ-009 | The landlord sees how long jobs take, per vendor |
| REQ-010 | withdrawn: Tenant and vendor chat in the app |
| REQ-011 | The landlord gets a weekly email of open jobs |

## Out of scope for v1
Native apps, rent collection, multi-landlord agencies.
