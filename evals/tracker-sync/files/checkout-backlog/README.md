# shop-checkout

Checkout service for the web shop: cart totals, guest checkout and the hand-off
to the payment provider's hosted page.

## Run

    make check     # unit tests (node --test, no dependencies)

## Where work is tracked

- Product backlog: `docs/product/backlog.md` (epics and stories, with acceptance
  criteria). Each epic and story records its Jira key once it has one.
- Jira project **SHOP** at https://tracker.example.test/browse/SHOP. Keys look
  like SHOP-41.
- Decisions: `docs/adr/`.
