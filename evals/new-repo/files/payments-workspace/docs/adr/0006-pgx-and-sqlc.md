# ADR-0006: pgx and sqlc, with goose migrations

Status: Accepted
Date: 2025-08-19
Supersedes: ADR-0002

## Context

GORM's auto-migration changed a column type in ledger-api's production
database during a deploy (incident PAY-188). Queries built at runtime were
hard to review.

## Decision

Go services reach Postgres through pgx, with queries written in SQL and
generated by sqlc. Schema changes are goose migrations, reviewed like code.
No ORM and no auto-migration.

## Consequences

Every new service starts on pgx and sqlc. ledger-api migrated in September
2025; nothing in the group uses GORM any more.
