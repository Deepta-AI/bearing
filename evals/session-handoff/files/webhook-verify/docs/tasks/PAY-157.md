# PAY-157 Verify and deduplicate payment webhooks

Acceptance criteria
1. A request whose `X-Signature` does not match is rejected with 401.
2. A request whose `X-Timestamp` is more than 5 minutes old is rejected with 400 (replay protection).
3. An event id already accepted is answered 200 and not processed again.
4. Accepted events are forwarded to the orders service; a 5xx from it is retried up to 3 times with backoff.

Blocked
- Staging has no `WEBHOOK_SIGNING_SECRET`, so nothing can be tried against the
  provider's sandbox. Requested from the platform team in INFRA-88 (open).
