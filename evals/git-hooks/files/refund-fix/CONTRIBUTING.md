# Contributing

- Branch per ticket: `feature/PAY-123-ShortName` or `bugfix/PAY-123-ShortName`.
- Commit subjects are Conventional Commits and start with the ticket, for
  example `fix(refunds): PAY-123 handle zero quantity`.
- `make check` must pass before you push.
- Never commit `.env` or any key; ask in the team channel for the sandbox keys.
