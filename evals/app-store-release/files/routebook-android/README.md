# RouteBook

Android app for delivery drivers: the day's route, stop by stop, with
turn-by-turn handed off to the driver's navigation app.

- Build: `./gradlew :app:bundleRelease` (the release engineer builds and
  uploads from their machine; signing keys are not in this repository).
- Play listing and Data safety answers live in `store/play/`.
- Each store release gets a record in `docs/releases/mobile/`.
