# Corner

The Corner grocery app for iPhone. Customers see their orders today; more
tabs are coming.

## Stack

- Swift 6 language mode, SwiftUI, iOS 17 minimum.
- `project.yml` is the project (XcodeGen). The `.xcodeproj` and
  `App/Info.plist` are generated by `make generate` and are git-ignored, so
  Info.plist keys (usage strings included) go under `info.properties` in
  `project.yml`.
- `App/` holds only what needs SwiftUI, UIKit or the bundle. Everything
  else lives in `Packages/CornerKit` (Core, Networking, Features) and must
  build and test with `swift test` on Linux, which is what CI runs. No
  UIKit, SwiftUI or CoreLocation imports in the package.
- View models are `@Observable @MainActor` classes with a `State` enum the
  view switches over (see `Features/Orders`). Screens start work in
  `.task`.
- Tokens live in the Keychain through `SecretStore`. Nothing sensitive in
  `UserDefaults`.
- Unit tests use Swift Testing. User-facing strings live in
  `App/Localizable.xcstrings` with dotted keys.

## Commands

    make generate   # project.yml -> Corner.xcodeproj
    make check      # swiftformat --lint, swiftlint --strict, swift test
    make test       # swift test in Packages/CornerKit
