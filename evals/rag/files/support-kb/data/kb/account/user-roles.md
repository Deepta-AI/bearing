# User roles and permissions

Updated: 2026-05-03

| Role | View payroll | Edit employees | Approve payroll run | Manage billing | Manage users |
| --- | --- | --- | --- | --- | --- |
| Owner | Yes | Yes | Yes | Yes | Yes |
| Payroll approver | Yes | Yes | Yes | No | No |
| Payroll editor | Yes | Yes | No | No | No |
| HR viewer | Yes (no salary) | No | No | No | No |
| Billing admin | No | No | No | Yes | No |

A company must always have at least one Owner. An Owner cannot remove their
own Owner role; another Owner must do it. Admin users count against the
plan's admin user limit; HR viewers do not.
