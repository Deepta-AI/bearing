# Report slowness, June notes

The big tenant complained that the order report takes several seconds.
Looked at it briefly: the rows are large and we marshal 60k of them with
encoding/json, which is reflection heavy. Pretty sure that is where the
time goes.

Next step: switch the report handler to jsoniter (drop-in replacement,
reportedly 3 to 5x faster). Did not get to it before the release freeze.
